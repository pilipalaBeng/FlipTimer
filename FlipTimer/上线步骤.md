## 5. 体验版真机自测（省一次驳回）

- [ ] **版本管理 → 开发版本 → 1.24.0 → 选为体验版**
- [ ] **成员管理 → 体验成员** 添加账号（上限 15 人）
- [ ] 扫体验二维码，真机逐条跑：

| 项目 | 通过标准 |
|---|---|
| 强制横屏 | 手机开竖排方向锁定，进小程序仍能横屏 |
| 翻转开始 | 横屏立放，上下翻 180°，计时开始 |
| 翻转停止 | 翻回正面，计时停止 |
| 点击路径 | 点屏幕任意位置 / 右上角按钮，同样能开始和停 |
| 切后台 | 切后台再回来，翻转仍然灵 |
| 说明面板 | 右上菜单第四项能打开，点空白能关 |
| 响铃与光色 | 到点响铃，光色按设置变化 |
| 右下角时间 | 显示 `HH:mm:ss`，带秒 |
| 静音状态 | 手机静音时的表现可接受 |

## 6. 提交审核

- [ ] **版本管理 → 开发版本 → 提交审核**
- [ ] 核对服务类目
- [ ] 勾选功能页面（本项目只有 `pages/clock/index`）
- [ ] **审核备注照抄下面这段**（必须写，否则审核员不知道该怎么玩）

```
本小程序为横屏翻转计时器。使用方式：手机横屏立放，
将手机上下翻转 180° 开始计时，翻回正面停止。
若不便翻转，可点击屏幕任意位置或右上角按钮走点击路径。
需授权设备方向（加速度计/陀螺仪）以判断翻转动作。
```

- [ ] 提交，等 2 小时 – 2 天

> 这是本项目**最大的驳回风险**：交互依赖物理翻转，审核员在桌上不会翻手机。
> 备注写清楚 + 确保点击路径可用，两条都做到基本不会被卡。

被驳回不要慌：看驳回理由改，改完重新上传新版本号再提交，不占用额度。
